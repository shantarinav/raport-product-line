# Дорожная карта

Рапорт развивается как набор легких локальных инструментов для проверки управленческих сценариев.

## Сейчас

- дашборды для ССЗ, Tessa, Печати и Техподдержки работают в браузере без обязательной серверной части;
- единая загрузка Excel/CSV на главной странице;
- локальные A3-разборы отклонений;
- локальная история ключевых показателей и месячные тренды;
- необязательный Raport LLM для анализа печати и подсказок A3;
- синтетические демо-данные для ССЗ и Техподдержки;
- публичные скриншоты ключевых сценариев;
- журнал архитектурных решений.

## Ближайшие шаги

- добавить синтетические демо-данные для Tessa и Печати;
- усилить A3-помощник как методический инструмент разбора причин, а не автозаполнитель формы;
- уточнить пользовательские сценарии для режимов «Руководитель» и «Аналитик»;
- улучшить установку и диагностику Raport LLM в небольшой корпоративной сети.

## Позже

- проверить, какие сценарии стоит переносить в промышленный BI-контур;
- развить методологию A3-разборов на базе проверенных пользовательских сценариев;
- оценить потребность в командном режиме только после подтверждения ценности локального A3.

## Не в ближайших планах

- замена корпоративного BI;
- хранение исходных Excel-файлов;
- универсальный конструктор отчетов;
- роли, пользователи и авторизация в локальной версии;
- обязательная серверная часть для базовых дашбордов.

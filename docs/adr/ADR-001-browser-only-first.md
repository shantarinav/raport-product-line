# ADR-001: Сначала браузерная локальная версия

## Статус

Принято

## Контекст

Рапорт создается как линейка легких управленческих дашбордов для Excel/CSV-выгрузок. Основной сценарий — быстро проверить управленческую гипотезу без запуска серверного проекта, ролей, интеграций и согласования витрин данных.

## Решение

Базовое приложение должно работать как статическое веб-приложение в браузере. Серверная часть может существовать только как необязательное расширение и не должна быть обязательной для открытия дашбордов.

## Последствия

Плюсы:

- простая публикация на GitHub Pages или корпоративном статическом сайте;
- исходные отчеты не нужно отправлять на сервер;
- ниже порог проверки новых управленческих сценариев.

Минусы:

- нет централизованного хранения;
- данные и A3-журнал локальны для браузера пользователя;
- командный режим требует отдельного архитектурного решения и не входит в локальную версию.

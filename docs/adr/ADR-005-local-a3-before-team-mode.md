# ADR-005: Сначала локальный A3, потом командный режим

## Статус

Принято

## Контекст

Командный режим с серверной частью, пользователями, ролями, авторизацией и общей базой может быть полезен, но он резко увеличивает сложность продукта. До такой инвестиции нужно доказать, что сам сценарий A3-разборов полезен пользователю.

## Решение

Командный режим поставлен на паузу. Сначала развивается локальный A3: локальный журнал облегченных протоколов разбора отклонений в браузере без серверной части, пользователей и ролей.

## Последствия

Плюсы:

- быстрее проверяется управленческий сценарий;
- не появляется преждевременная серверная архитектура;
- локальная версия остается простой и безопасной.

Минусы:

- нет совместной работы нескольких пользователей;
- журнал A3 локален для браузера;
- перенос в командный режим потребует отдельного решения после подтверждения ценности локального A3.

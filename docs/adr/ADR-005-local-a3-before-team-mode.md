# ADR-005: Local A3 before Team mode

## Status

Accepted

## Context

Командный режим с backend, пользователями, ролями, авторизацией и общей базой может быть полезен, но он резко увеличивает сложность продукта. До такой инвестиции нужно доказать, что сам сценарий A3-разборов полезен пользователю.

## Decision

Team mode поставлен на паузу. Сначала развивается Local A3: локальный журнал облегченных протоколов разбора отклонений в браузере без backend, пользователей и ролей.

## Consequences

Плюсы:

- быстрее проверяется управленческий сценарий;
- не появляется преждевременная серверная архитектура;
- Local-версия остается простой и безопасной.

Минусы:

- нет совместной работы нескольких пользователей;
- журнал A3 локален для браузера;
- перенос в Team mode потребует отдельного решения после подтверждения ценности Local A3.

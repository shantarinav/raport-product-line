# ADR-003: No raw data persistence

## Status

Accepted

## Context

Даже синтетические выгрузки могут иметь структуру, похожую на рабочие отчеты: документы, заявки, показатели и управленческие признаки. При этом Рапорту нужна локальная история KPI и журнал A3-разборов.

## Decision

Не сохранять исходные Excel/CSV-файлы и сырые строки отчетов. Локальная история хранит только агрегированные KPI snapshots. Local A3 хранит ограниченный snapshot конкретного отклонения.

## Consequences

Плюсы:

- ниже риск утечки данных;
- публичный репозиторий может содержать только синтетические демо-данные;
- архитектурная граница хранения становится проверяемой.

Минусы:

- невозможно восстановить исходный отчет из истории;
- часть контекста для будущего анализа нужно заново загружать из файла;
- пользователь может вручную вписать чувствительные данные в A3, поэтому UX и документация должны предупреждать о локальном характере хранения.

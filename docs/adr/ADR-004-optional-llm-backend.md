# ADR-004: Raport LLM как необязательное ИИ-расширение

## Статус

Принято

## Контекст

ИИ полезен для уточнения нецелевой печати и черновиков A3-формулировок, но локальная модель может быть недоступна, медленна или неприемлема для части пользователей.

## Решение

Raport LLM реализуется как optional backend extension. Фронтенд работает без него. Пользователь явно включает ИИ-помощник в настройках. При ошибке backend дашборды используют безопасный fallback.

## Последствия

Плюсы:

- базовая Local-версия не зависит от LLM;
- ИИ можно проверять как отдельную продуктовую гипотезу;
- backend можно разместить локально или в небольшой корпоративной сети.

Минусы:

- появляется отдельный контур настройки и диагностики;
- качество и скорость зависят от локальной модели;
- нужно строго ограничивать payload, который отправляется в LLM.

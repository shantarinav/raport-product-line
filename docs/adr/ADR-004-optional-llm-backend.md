# ADR-004: Raport LLM как необязательное ИИ-расширение

## Статус

Принято

## Контекст

ИИ полезен для уточнения нецелевой печати и черновиков A3-формулировок, но локальная модель может быть недоступна, медленна или неприемлема для части пользователей.

## Решение

Raport LLM реализуется как необязательное ИИ-расширение с локальной серверной частью. Веб-интерфейс работает без него. Пользователь явно включает ИИ-помощник в настройках. При ошибке сервиса дашборды используют безопасный резервный режим.

## Последствия

Плюсы:

- базовая локальная версия не зависит от языковой модели;
- ИИ можно проверять как отдельную продуктовую гипотезу;
- сервис можно разместить локально или в небольшой корпоративной сети.

Минусы:

- появляется отдельный контур настройки и диагностики;
- качество и скорость зависят от локальной модели;
- нужно строго ограничивать данные, которые отправляются в языковую модель.

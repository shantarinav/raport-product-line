# ADR-002: Статическая публикация и маршруты через #

## Статус

Принято

## Контекст

Рапорт должен публиковаться как статический сайт в любой папке: GitHub Pages, корпоративный каталог, внутренний портал или тестовый адрес. Не всегда можно настроить сервер так, чтобы он правильно отдавал приложение для всех внутренних маршрутов.

## Решение

Использовать маршруты через `#`: `#/ssz`, `#/print`, `#/support`, `#/a3`.

## Последствия

Плюсы:

- сборка работает в любой папке сайта;
- серверу не нужна специальная настройка маршрутов;
- публикация `dist/` остается простой.

Минусы:

- адреса выглядят менее привычно, чем обычные пути;
- при будущем серверном режиме потребуется отдельное решение, если понадобится поисковая индексация или полноценная серверная маршрутизация.

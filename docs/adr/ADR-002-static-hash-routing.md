# ADR-002: Статическая публикация и hash-маршрутизация

## Статус

Принято

## Контекст

Рапорт должен публиковаться как статический сайт в любой папке: GitHub Pages, корпоративный каталог, внутренний портал или тестовый URL. Не всегда можно настроить серверный fallback для SPA-маршрутов.

## Решение

Использовать hash-routing: `#/ssz`, `#/print`, `#/support`, `#/a3`.

## Последствия

Плюсы:

- сборка работает в любой папке сайта;
- серверу не нужен специальный fallback;
- публикация `dist/` остается простой.

Минусы:

- URL менее «красивые», чем обычные path routes;
- при будущем серверном режиме потребуется отдельное решение, если понадобится SEO или полноценный router на сервере.

# Технологические правила интерфейса для «Рапорт»

# Технологический стандарт интерфейса

Интерфейс должен использовать:

- **Tailwind CSS** — для стилей, сетки, отступов, состояний, адаптивности и цветовых токенов.
- **shadcn/ui** — для базовых UI-компонентов.
- **lucide-react** — для всех иконок.

Запрещено использовать:

- собственные SVG-иконки, если есть подходящая иконка в `lucide-react`;
- сторонние UI-kit библиотеки, кроме `shadcn/ui`;
- CSS-in-JS;
- inline styles;
- новые отдельные CSS-файлы под конкретный дашборд без необходимости;
- hardcoded-цвета внутри компонентов, если можно использовать Tailwind token или CSS variable.

Допустимо использовать CSS-файлы только для:

- общих CSS variables;
- базовых theme tokens;
- технических случаев, которые сложно или нецелесообразно выразить Tailwind-классами.

Все новые или обновленные UI-компоненты должны быть React-компонентами, стилизованными через Tailwind classes и, где уместно, построенными на shadcn/ui primitives.


## shadcn/ui

Для базовых компонентов использовать shadcn/ui.

Рекомендуемые компоненты:

- `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`;
- `Button`;
- `Badge`;
- `Alert`, `AlertTitle`, `AlertDescription`;
- `Progress`;
- `Separator`;
- `Tabs`;
- `Tooltip`;
- `Input`;
- `Select`;
- `Table`;
- `Switch`;
- `ToggleGroup`;
- `DropdownMenu`;
- `Popover`;
- `Command`.

Использовать shadcn/ui как визуальную и структурную основу, но не менять бизнес-логику существующих виджетов.

# Правила по иконкам

Все иконки брать только из `lucide-react`.

Не создавать собственные SVG-иконки и не копировать SVG вручную в компоненты.

Рекомендуемые иконки:

- `FileSpreadsheet` — CSV/XLS/XLSX, таблицы, файл отчета;
- `UploadCloud` — drag-and-drop загрузка;
- `ShieldCheck` — локальная обработка файла в браузере;
- `CheckCircle2` — успешное состояние;
- `AlertTriangle` — предупреждение;
- `CircleX` — ошибка;
- `SearchCheck` — определение типа отчета;
- `Gauge` — аналитика / дашборд;
- `Printer` — дашборд печати;
- `ClipboardCheck` — Tessa / исполнительская дисциплина;
- `ClipboardList` — ССЗ / задания;
- `Factory` — производственный контекст;
- `Filter` — фильтры;
- `RefreshCcw` — сброс фильтров;
- `Info` — пояснение.

Правила:

- использовать иконки сдержанно;
- иконка должна иметь смысловую функцию;
- не использовать иконки как декор;
- размер обычно 16–24 px;
- `strokeWidth={2}`;
- цвет задавать Tailwind-классами;
- для одинаковых смыслов использовать одинаковые иконки во всех дашбордах.


## Tailwind CSS

Правила:

- все новые стили писать Tailwind-классами;
- переиспользуемые варианты оформлять через `className`, `cn()` и variant-паттерны;
- общие цвета и размеры выносить в `theme.css` или Tailwind theme;
- не плодить локальные CSS-файлы для каждого дашборда;
- старые CSS-файлы не удалять резко, сначала изолировать и постепенно вытеснять.

## Запреты

Запрещено:

- добавлять Material UI, Ant Design, Chakra UI или другой UI-kit;
- создавать собственный набор SVG-иконок;
- использовать декоративные изображения как иконки интерфейса;
- менять бизнес-логику ради внедрения shadcn/ui;
- менять поведение фильтров ради нового визуального компонента;
- менять поведение переключателей ради нового визуального компонента.

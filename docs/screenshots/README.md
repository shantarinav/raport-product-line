# Скриншоты для GitHub

Скриншоты должны показывать управленческий сценарий, а не только интерфейс.

## Набор для README

1. `01-landing-upload.png` — главная загрузка отчета.
2. `02-ssz-main-insight.png` — ССЗ: главный вывод и зона внимания.
3. `03-a3-review-ssz.png` — A3-разбор отклонения.
4. `04-a3-journal.png` — журнал A3-разборов.
5. `05-support-sla-overview.png` — Support: SLA и поток заявок.
6. `06-support-overdue-tail.png` — Support: самые долгие нарушения SLA.
7. `07-settings-ai-history.png` — настройки возможностей: ИИ-помощник, тренды и история.

## Правила

- использовать только синтетические данные;
- использовать только синтетические ФИО, документы, заявки и адреса;
- кадр должен объяснять управленческую пользу;
- ширина изображения — 1440 px или 1600 px;
- формат — PNG или WebP;
- после обновления визуального контракта скриншоты нужно пересматривать.

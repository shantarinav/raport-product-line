# Короткие промпты для Codex: ССЗ как визуальный эталон

## 1. Анализ ССЗ

```md
Проанализируй legacy/ssz как визуальный эталон линейки «Рапорт».

Ничего не меняй.

Создай docs/ssz-visual-style-audit.md и опиши:
- цвета;
- типографику;
- загрузочный экран;
- шапку дашборда;
- переключатели;
- статусную полоску фильтра;
- фильтры;
- подход к иконкам;
- карточки;
- графики;
- таблицы;
- состояния ошибок и пустых данных;
- отступы и сетку;
- mapping на Tailwind;
- mapping на shadcn/ui;
- mapping иконок на lucide-react.
```

## 2. Анализ Tessa и Print

```md
Проанализируй legacy/tessa и legacy/print перед применением стиля ССЗ.

Ничего не меняй.

Создай docs/tessa-print-migration-analysis.md и опиши:
- расчеты;
- KPI;
- виджеты;
- фильтры;
- переключатели;
- таблицы;
- графики;

- риски миграции;
- какие элементы можно заменить на shadcn/ui;
- какие иконки нужно заменить на lucide-react.
```

## 3. Shared UI на основе ССЗ

```md
Создай shared/ui и theme.css на основе визуального стиля legacy/ssz.

Не придумывай новую дизайн-систему. Используй выводы из docs/ssz-visual-style-audit.md.

Требования:
- Tailwind CSS для стилей;
- shadcn/ui для базовых компонентов;
- lucide-react для всех иконок;
- не создавать собственные SVG-иконки;
- не использовать inline styles;
- не использовать CSS-in-JS.

Компоненты:
PageShell, TopBar, DashboardHeader, FileDropZone, MetricCard, SectionCard, ProblemBadge, FilterPanel, FilterStatusBar, DashboardSwitch, DataTable, ChartCard, EmptyState, ErrorState, IconLabel.

TopBar должен содержать только ссылку на главную страницу /. Не добавляй ссылки на дашборды.

Не меняй бизнес-логику дашбордов.
```

## 4. Tessa в стиле ССЗ

```md
Примени визуальный стиль ССЗ к дашборду /tessa.

Это визуальная миграция, а не редизайн UX.

Используй:
- Tailwind CSS для стилей;
- shadcn/ui для базовых компонентов;
- lucide-react для иконок.

Сохрани:
- расчеты;
- фильтры;
- поведение фильтров;
- переключатели;
- значения переключателей по умолчанию;
- расположение виджетов;
- порядок виджетов;
- таблицы;
- графики;
- сценарий пользователя.

Измени только внешний вид в стиле ССЗ.

После изменений выполни npm run build.
```

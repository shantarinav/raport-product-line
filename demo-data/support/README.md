# Демонстрационные данные Support

В этой папке находится синтетический Excel-файл для демонстрации работы дашборда `#/support`.

Файл:

- `demo-support-synthetic-june-2026.xlsx`

Назначение:

- показать загрузку отчета через главную страницу `#/`;
- проверить распознавание отчета техподдержки;
- продемонстрировать KPI SLA, фильтры, SLA по дням, SLA по темам и хвост просрочек;
- проверить новый формат с чистым рабочим временем `SLA_work_time`;
- использовать безопасные данные для презентаций, разработки и тестовых показов.

Параметры набора:

- период: `18.06.2026 - 25.06.2026`;
- лист: `ticket`;
- заявок: `90`;
- формат: новый Support-формат с колонками `SLA_work_time`, `Выполнение SLA`, `Full_time`;
- в наборе есть заявки в SLA, нарушения SLA и открытые заявки `В работе`.

Данные полностью синтетические:

- номера заявок сгенерированы;
- темы обращений демонстрационные;
- пользователи, компьютеры, адреса, телефоны и реальные обращения не используются;
- файл не содержит персональных данных и реальных данных техподдержки.

Не заменять этот файл реальными отчетами. Реальные файлы для локальной проверки должны оставаться в `load_file/`, который исключен из Git.

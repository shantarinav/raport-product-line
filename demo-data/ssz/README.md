# Демонстрационные данные ССЗ

В этой папке находится синтетический Excel-файл для демонстрации работы дашборда `#/ssz`.

Файл:

- `demo-ssz-synthetic-may-2026.xlsx`

Назначение:

- показать загрузку отчета через главную страницу `#/`;
- проверить распознавание отчета ССЗ;
- продемонстрировать KPI, фильтры, срезы, зоны внимания и месячный тренд;
- использовать безопасные данные для презентаций, разработки и тестовых показов.

Параметры набора:

- период: `01.05.2026 - 20.05.2026`;
- лист: `TDSheet`;
- ССЗ: `60`;
- строк операций: `180`;
- доля работ по технологии: примерно `57,6%`.

Данные полностью синтетические:

- цеха имеют демонстрационные названия;
- мастера и исполнители обезличены;
- заказы и изделия сгенерированы;
- реальные производственные данные не используются.

Не заменять этот файл реальными отчетами.

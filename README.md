# Рапорт

**Рапорт** — линейка легких аналитических инструментов для руководителей и специалистов промышленного предприятия.

**Слоган:** Excel докладывает главное.

## Идея продукта

На промышленных предприятиях значительная часть управленческой информации живет в Excel, CSV-выгрузках, локальных отчетах и разрозненных таблицах.

Из-за этого руководителям сложно быстро увидеть главное:

- где возникло отклонение;
- какой участок требует внимания;
- кто или что формирует основную часть проблемы;
- какие действия нужно предпринять в первую очередь.

«Рапорт» решает эту задачу через простые дашборды, которые превращают выгрузки данных в понятную управленческую картину.

## Для кого

- руководители производственных подразделений;
- мастера и начальники участков;
- специалисты планово-диспетчерских служб;
- ИТ- и бизнес-аналитики;
- руководители, которым нужна быстрая диагностика процесса.

## Продукты линейки

| Продукт | Назначение | Статус |
|---|---|---|
| Рапорт: качество ССЗ | Контроль качества оформления сменно-суточных заданий | MVP |
| Рапорт: контроль печати | Анализ печати, нагрузки на устройства и точек оптимизации затрат | MVP |

## Принципы

- быстрый запуск без тяжелой ИТ-инфраструктуры;
- работа с выгрузками CSV / Excel;
- понятные управленческие показатели;
- акцент на отклонениях и точках внимания;
- минимум лишней визуализации;
- возможность дальнейшей интеграции с корпоративными системами.

## Моя роль

- формирование продуктовой идеи;
- описание бизнес-проблемы;
- проектирование логики показателей;
- постановка задач на разработку;
- проверка результата с точки зрения пользователя и руководителя;
- развитие подхода к управленческой аналитике.

## Безопасность данных

Репозиторий содержит демонстрационное описание продуктовой линейки.

Не публикуются:

- реальные производственные данные;
- персональные данные;
- внутренние адреса, логины, пароли и токены;
- коммерчески чувствительная информация;
- материалы, подпадающие под NDA или внутренние ограничения работодателей.

Все примеры данных должны быть обезличены или синтетически сгенерированы.

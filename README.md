# Рапорт

**Рапорт** — линейка легких фронтенд-дашбордов для анализа Excel и CSV-отчетов.

Слоган: **Excel докладывает главное**.

Файлы обрабатываются локально в браузере и не передаются на сервер.

## Идея продукта

На промышленных предприятиях значительная часть управленческой информации живет в Excel, CSV-выгрузках, локальных отчетах и разрозненных таблицах.

Из-за этого руководителям сложно быстро увидеть главное:

- где возникло отклонение;
- какой участок требует внимания;
- кто или что формирует основную часть проблемы;
- какие действия нужно предпринять в первую очередь.

«Рапорт» решает эту задачу через простые дашборды, которые превращают выгрузки данных в понятную управленческую картину.

## Для кого

- руководители производственных подразделений;
- мастера и начальники участков;
- специалисты планово-диспетчерских служб;
- ИТ- и бизнес-аналитики;
- руководители, которым нужна быстрая диагностика процесса.

## Дашборды

- `#/` — единая точка загрузки отчетов.
- `#/ssz` — качество оформления ССЗ.
- `#/tessa` — исполнительская дисциплина Tessa.
- `#/print` — анализ печати.
- `#/support` — SLA закрытых заявок техподдержки.

## Продукты линейки

| Продукт | Назначение | Статус |
|---|---|---|
| Рапорт: качество ССЗ | Контроль качества оформления сменно-суточных заданий | MVP |
| Рапорт: исполнительская дисциплина Tessa | Анализ договорных согласований и дедлайнов | MVP |
| Рапорт: контроль печати | Анализ печати, нагрузки на устройства и точек оптимизации затрат | MVP |
| Рапорт: техподдержка | Анализ SLA закрытых заявок техподдержки | MVP |

## Принципы

- быстрый запуск без тяжелой ИТ-инфраструктуры;
- работа с выгрузками CSV / Excel;
- понятные управленческие показатели;
- акцент на отклонениях и точках внимания;
- минимум лишней визуализации;
- возможность дальнейшей интеграции с корпоративными системами.

## Логознак

В проекте в качестве логознака используется иконка `FileSpreadsheet` из `lucide-react`.

- без PNG;
- в шапке: скругленный контейнер `40x40`, темный фон, белая иконка;
- размер иконки: `24px`;
- `strokeWidth`: `2.3`;
- favicon приложения: [`public/favicon.svg`](public/favicon.svg).

```bash
npm run check
```

## Production-сборка

```bash
npm run build
```

После сборки статические файлы находятся в `dist/`.

## Публикация

Production-сборка не привязана к домену или папке. Ее можно разместить, например:

```txt
https://bi.ekb.ru/raport/
https://example.ru/
https://example.ru/any/folder/
```

На сервер нужно переносить содержимое `dist/` в выбранную директорию.

Приложение использует hash-routing, поэтому серверу не нужен отдельный fallback для маршрутов дашбордов.

После публикации адреса будут выглядеть так: `https://site/folder/#/print`.

## Локальная проверка production-сборки


## Безопасность данных

Репозиторий содержит демонстрационное описание продуктовой линейки и исходный код фронтенд-дашбордов.

Не публикуются:

- реальные производственные данные;
- персональные данные;
- внутренние адреса, логины, пароли и токены;
- коммерчески чувствительная информация;
- материалы, подпадающие под NDA или внутренние ограничения работодателей.

Все примеры данных обезличены или синтетически сгенерированы.

## Известный риск зависимостей

`npm audit --omit=dev` сообщает о high-severity advisories в пакете `xlsx`. Автоматического исправления npm не предлагает. Сейчас Excel-файлы обрабатываются локально в браузере, ограничение загрузки — до 20 Мб.

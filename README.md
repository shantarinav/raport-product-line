# Рапорт

**Рапорт** — легкие локальные дашборды для проверки управленческих сценариев на Excel/CSV-выгрузках.

> Excel докладывает главное

Рапорт помогает быстро загрузить отчет, увидеть отклонения, найти зону внимания и оформить A3-разбор. Это не замена BI-платформы, а промежуточный слой для проверки управленческой гипотезы до тяжелой автоматизации.

[Открыть демо](https://shantarinav.github.io/raport-product-line/) · [Кейс проекта](docs/SHOWCASE.md) · [Архитектура](docs/ARCHITECTURE.md) · [Выпуск](https://github.com/shantarinav/raport-product-line/releases/tag/raport-local-v1.1.0)

## Что внутри

- Единая загрузка Excel/CSV через главную страницу.
- Автоматическое определение типа отчета по содержимому файла.
- Дашборды: ССЗ, Tessa, Печать, Техподдержка.
- Режимы «Руководитель» и «Аналитик».
- Главный вывод, KPI, фильтры и зоны внимания.
- Локальный A3 — журнал разборов отклонений в браузере.
- Локальная история KPI и месячные тренды без сохранения исходных строк.
- Необязательный Raport LLM для ИИ-подсказок и уточнения личной печати.

## Быстрый старт

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run check
```

Сборка для публикации:

```bash
npm run build
```

После сборки статические файлы находятся в `dist/`.

## Демонстрационные данные

В репозитории используются только синтетические демонстрационные данные.

- `demo-data/ssz/demo-ssz-synthetic-may-2026.xlsx` — синтетический отчет ССЗ.
- `demo-data/support/demo-support-synthetic-june-2026.xlsx` — синтетический отчет техподдержки с `SLA_work_time`.

Файлы можно загрузить через главную страницу `#/`.

## Архитектура в двух словах

Базовый Рапорт — статическое веб-приложение. Он работает без обязательной серверной части, авторизации, серверной базы и отправки исходных отчетов на сервер.

- исходные Excel/CSV-файлы обрабатываются в браузере;
- локальная история хранит только агрегированные KPI;
- A3 хранит ограниченный снимок отклонения, а не весь отчет;
- Raport LLM является необязательным расширением и выключен по умолчанию;
- приложение использует маршруты через `#` и может публиковаться в любой папке сайта.

Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Публикация

Сборка для публикации не привязана к домену или папке. На сервер нужно переносить содержимое `dist/`.

Примеры адресов после публикации:

```txt
https://site/folder/#/print
https://site/folder/#/ssz
https://site/folder/#/support
```

## Необязательный Raport LLM

`backend/raport-llm/` — необязательный локальный ИИ-сервис. Приложение работает без него.

Сценарии:

- Print — уточнение кандидатов личной печати;
- A3 — черновики формулировок проблемы, причины, действия, результата и проверки.

Документация: [backend/raport-llm/README.md](backend/raport-llm/README.md).

## Известный риск зависимостей

`npm audit --omit=dev` сообщает о предупреждениях высокого уровня риска в пакете `xlsx`. Автоматического исправления npm не предлагает. Сейчас Excel-файлы обрабатываются локально в браузере, ограничение загрузки — до 20 Мб.

# Правила использования иконок «Рапорт»

Этот файл объясняет Codex, какую иконку использовать для разных блоков, KPI, виджетов, состояний и разделов в дашбордах линейки **«Рапорт»**.

## Главный принцип

Иконки нужны не для украшения, а для быстрого визуального распознавания смысла блока.

> Один блок — одна смысловая иконка.

## Оптимизация ассетов

Перед публикацией дашборда обязательно проверить размер иконок и логотипов.

Правила:

- не хранить в публикационном пакете неиспользуемые иконки;
- не использовать PNG 1000+ px для иконки, которая отображается как 18-24 px;
- для UI-иконок обычно достаточно 64-96 px по длинной стороне;
- для компактного логотипа в шапке обычно достаточно 256-480 px по длинной стороне;
- после сжатия проверить, что нет черных углов, артефактов прозрачности и размытости;
- если иконка используется рядом с текстовым заголовком, `alt` должен быть пустым;
- если иконка сама является действием без текстовой подписи, нужна доступная подпись через `aria-label` или видимый tooltip.

Цель: брендовые ассеты должны помогать восприятию, но не утяжелять загрузку сайта.

## Папка с иконками

```text
assets/brand/icons/
```

или для React/Vite:

```text
public/assets/brand/icons/
```

## Правила выбора

### Для KPI

Сначала определить смысл показателя:

- количество → `icon-count.png`
- процент / доля → `icon-percent.png`
- план / цель / норматив → `icon-target.png`
- отклонение → `icon-deviation.png`
- время / срок → `icon-time.png`
- тренд / динамика → `icon-trend.png`
- рейтинг / топ → `icon-ranking.png`
- сравнение → `icon-compare.png`
- проверка данных → `icon-validation.png`
- источник / файл → `icon-source.png`
- если тип не ясен → `icon-kpi.png`

### Для оргструктуры

- человек / ответственный → `icon-user.png`
- подразделение → `icon-department.png`
- цех / участок → `icon-workshop.png`
- офис / административная служба → `icon-office.png`

## Команда для Codex

```text
В проект добавлены иконки бренда «Рапорт» в папку assets/brand/icons.

Используй файл raport-ui/icons-guide.md как словарь применения иконок.

Правила:
- выбирай иконку по смыслу блока или KPI;
- один блок — одна ключевая иконка;
- не используй иконки декоративно;
- не используй одну иконку для разных смыслов;
- для KPI сначала определяй тип показателя;
- для оргструктуры различай человека, подразделение, цех и офис.
```

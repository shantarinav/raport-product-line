# Raport LLM

`backend/raport-llm` — необязательный локальный ИИ-сервис Рапорта.

Фронтенд Рапорта должен работать без этого сервиса. Если сервис не запущен, дашборды продолжают работать в обычном Local-режиме.

## Что умеет

- `Print` — уточняет словарные кандидаты личной печати локальной LLM-моделью.
- `A3` — помогает сформулировать черновик проблемы, гипотез причин, контрмер, ожидаемого результата и критерия проверки.

ИИ не пересчитывает KPI, не меняет бизнес-логику дашбордов и не применяет решения автоматически.

## Запуск

```bash
npm run backend:raport-llm
```

Проверка:

```bash
curl http://127.0.0.1:8787/health
```

## Настройки

Скопируйте `.env.example` в `.env` и настройте значения под локальный ПК или сервер в корпоративной сети.

Основные параметры:

- `RAPORT_LLM_HOST` — адрес, на котором слушает сервис.
- `RAPORT_LLM_PORT` — порт сервиса.
- `RAPORT_LLM_ALLOWED_ORIGINS` — сайты Рапорта, которым разрешен доступ к сервису.
- `RAPORT_LLM_API_KEY` — необязательный ключ доступа для локальной сети.
- `RAPORT_LLM_OLLAMA_CHAT_URL` — адрес Ollama chat API.
- `RAPORT_LLM_MODEL` — локальная модель Ollama для быстрых задач, по умолчанию `qwen3:1.7b`.
- `RAPORT_LLM_A3_MODEL` — отдельная модель для A3-помощника, по умолчанию `qwen3:4b`.
- `RAPORT_LLM_CONCURRENCY` — число параллельных запросов к модели. Для CPU обычно оставлять `1`.

Практический вариант для обычного ПК:

- Print: `RAPORT_LLM_MODEL=qwen3:1.7b`, чтобы быстрее проверять много коротких названий документов.
- A3: `RAPORT_LLM_A3_MODEL=qwen3:4b`, чтобы получать более осмысленные управленческие формулировки.


## API

### Health

```http
GET /health
```

### Print

Совместимые маршруты:

```http
POST /api/print/classifications/lookup
POST /api/print/classifications/classify-missing
POST /api/print/classify-personal
```

### A3

```http
POST /api/a3/assist
```

В запрос A3 передается только ограниченный snapshot разбора: дашборд, период, отклонение, показатель, факт, цель, масштаб и краткое evidence summary.

Запрещено передавать исходные Excel-строки, весь state дашборда, файлы `File/Blob`, ключи и пользовательские настройки.

## Безопасное поведение

- При недоступной Ollama сервис возвращает безопасный fallback.
- При недоступном `raport-llm` фронтенд продолжает работать без ИИ.
- A3-помощник показывает только предложения. Пользователь сам решает, какие формулировки вставить.
